# Artifacts

Self-contained HTML documents for this project. Each file is standalone — open it
in any browser and it renders on its own, with no external dependencies. The
canonical, editable source for the GDD is
[`../game-design-document.md`](../game-design-document.md); the other two are
point-in-time documents.

| File | What it is |
| --- | --- |
| [`dilli-khoj-gdd.html`](dilli-khoj-gdd.html) | Game Design Document — the consolidated design reference (concept, pillars, world, gameplay, economy, grading, curriculum). |
| [`dilli-khoj-build-spec.html`](dilli-khoj-build-spec.html) | Implementation spec (revision 4) — hosting, architecture, the twenty ruins, anti-cheat, submission path, data model, work packages. |
| [`dilli-khoj-field-report.html`](dilli-khoj-field-report.html) | Illustrated field report / walkthrough deck with in-game screenshots (large — embeds images). |
